# AI development disclosure

OpenAI Codex was used as a development tool for C++ and Python implementation,
refactoring, debugging, automated tests, documentation, and packaging. Falendar
defined the product, directed the work, selected the design, and performed the
in-game acceptance testing.

The repository contains the resulting source, transformation scripts, tests,
and pinned provenance so the work can be reviewed and reproduced. The released
plugin does not contain an AI model, call an AI service, make network requests,
or send telemetry.
