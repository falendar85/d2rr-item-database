# Changelog

## 0.5.1 - 2026-09-21

- Makes the **Alt+S** open/close shortcut explicit in the public description and
  installation documentation.
- Corrects installation guidance for the mod-local D2RLoader plugin directory.
- Removes the incompatible standard Hub asset archive; use the manual GitHub
  package until the launcher supports native D2RLoader extension destinations.

## 0.5.0 - 2026-09-21

### Added

- Cube Recipes, Item Enchants, Item Crafting, and Orbs tabs.
- Structured, color-coded recipe and crafting tables based on the Reimagined wiki.
- Seven Power Orb guides and gear-specific corruption affix tables.
- Website-style item filters, search, paging, and persistent rune selector.
- Three-tier base family comparisons and complete grouped set display.
- Alt+S hotkey and `itemdb` console command.
- Offline release packaging for GitHub and the Reimagined Hub.

### Fixed

- Repeated-page text corruption and lifetime bugs from the earlier in-game UI.
- Cursor flashing, disappearing cursors, control repaint artifacts, and scrollbar dragging.
- Set bonus ordering and item-specific bonus grouping.
- Detail overflow, tab alignment, base-column spacing, and conditional scrollbars.

### Privacy

- The plugin remains fully offline, read-only, and telemetry-free.
