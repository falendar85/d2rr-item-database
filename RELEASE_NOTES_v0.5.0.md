# D2RR Item Database v0.5.0

> **Superseded by v0.5.1.** The v0.5.0 Hub archive used a destination supported
> for mod assets but not for native D2RLoader extensions. Use the v0.5.1 manual
> package and follow `INSTALL.md`.

The first public release provides an offline in-game reference for D2R
Reimagined items, recipes, crafting, enchants, Power Orbs, and corruption
affixes. Open or close it with **Alt+S**.

## Downloads

- `D2RR-Item-Database-v0.5.0.zip` — manual GitHub Release installation.
- `D2RR-Item-Database-Hub-v0.5.0.zip` — Reimagined Hub attachment.
- `SHA256SUMS.txt` — checksums for both archives.

Use the Hub ZIP only as the attachment to the Reimagined launcher plugin post.
Manual users should follow `INSTALL.md`.

## Compatibility

- Windows x64
- D2R Reimagined 3.0.12
- D2RLoader Plugin ABI 4
- Designed for common 720p and larger game resolutions; very small windows may
  reduce the available detail area.

## Verification

- Native C++ core and prototype tests pass.
- Python generator/guide tests pass against pinned sources.
- Release package structure, JSON parsing, embedded version, and SHA-256 hashes
  are checked by the packaging script.
- The feature set was repeatedly exercised in-game by Falendar.
