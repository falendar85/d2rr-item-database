# D2RR Item Database v0.5.1

This patch corrects installation guidance and makes the overlay shortcut clear
in the public description and documentation. Press **Alt+S** to open the database
and **Alt+S** again to close it.

## Download and install

Download `D2RR-Item-Database-v0.5.1.zip` and `SHA256SUMS.txt`. Close the game,
then extract the ZIP into:

`<Diablo II Resurrected>\mods\Reimagined\`

After extraction, the DLL must be at:

`mods\Reimagined\d2rloader\plugins\d2rl-item-database.dll`

The standard Reimagined Hub asset installer currently writes inside
`Reimagined.mpq`, which is not a D2RLoader scan location. This release therefore
ships one manual package. The Reimagined team may separately provide the plugin
through its approved optional-extension system for supported ladders.

## Compatibility

- Windows x64
- D2R Reimagined 3.0.12
- D2RLoader Plugin ABI 4

All licensing, attribution, permission, privacy, and AI-development disclosures
are included in the package.
