# D2RR Item Database 0.5.2

This release packages the existing Item Database overlay for installation through
the standard D2RLoader Extension catalog. The interface and runtime behavior are
unchanged from 0.5.1.

## Installation change

- `d2rl-item-database.dll` now contains the complete offline item database and
  guide catalog.
- D2RLoader can install the single DLL without loose companion JSON files.
- The manual mod-local ZIP remains available as a fallback.
- Press **Alt+S** to open or close the overlay.

The plugin remains offline, read-only, and telemetry-free. Reimagined catalog
and guide data are distributed with permission from the D2R Reimagined owner;
full credits, third-party notices, permissions, privacy information, and the AI
assistance disclosure remain in the repository and manual package.
