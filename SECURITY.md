# Security policy

Please report a suspected security issue through a private GitHub Security
Advisory for this repository. If private reporting is unavailable, open an issue
requesting a private contact channel without posting exploit details.

Supported release: `0.5.x`.

The plugin is client-only, performs no networking, and loads two bundled JSON
files. Reports involving modified third-party binaries, unsupported loaders, or
unofficial repacks may require reproduction with the official release archive.
