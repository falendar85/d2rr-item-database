# Permissions and provenance

## D2R Reimagined distribution permission

On September 21, 2026, Collin, the D2R Reimagined owner, told Falendar:

> You're welcome to distribute the plugin on the hub, and we can add it as an
> optional extensions for ladders.

Collin also agreed to review the contributor list for omissions. Falendar
retains the original Discord message screenshot as permission evidence.

This repository treats that message as permission to distribute this plugin,
including the offline transformed catalog and guide files it needs, through the
Reimagined Hub and as an optional ladder extension. It does not claim that the
D2R Reimagined website, wiki, or mod repositories have been relicensed for
unrelated reuse.
